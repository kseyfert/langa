# Визуальный стиль экосистемы AnkiBook

Этот файл — для Claude Code в новом проекте. Новый инструмент должен выглядеть
как продукт той же семьи, что и AnkiBook: тот же «бумажный» спокойный вид,
те же токены, те же приёмы. Всё ниже снято с работающего кода AnkiBook
(`web/src/styles/*`, `web/src/components/*`, `web/src/steps/*.css`).

Здесь только визуальный стиль. Стек, структура кода и раскладка файлов
проекта описаны в его собственных документах.

---

## 1. Характер

- **Инструмент, а не продукт на продажу.** Никаких лендинговых приёмов:
  нет героев, градиентов, теней на карточках, иллюстраций, эмодзи в интерфейсе.
- **Бумага и чернила.** Холодная серо-зелёная бумага, почти чёрный текст,
  тонкие линейки 1px. Структура держится на линейках и отступах, а не на
  плашках и тенях.
- **Цвет несёт смысл, а не украшает.** Акцентов мало, и каждый что-то
  означает. Если цвет ничего не означает — его нет.
- **Данные — моноширинным.** Числа, счётчики, леммы, частотность, пути
  файлов — `--font-data` с `tabular-nums`. Они читаются как таблица.
- **Узкая колонка.** Одна колонка `max-width: 860px` по центру. Это чтение,
  а не дашборд.
- **Тихий интерфейс.** Подсказки мелкие и приглушённые (`.muted`, `--t-xs`).
  Решения на виду и обратимы: отключённое не исчезает, а бледнеет до 0.35–0.4.

## 2. Токены — копировать дословно

Файл `src/styles/tokens.css`. Это **единственное** место с конкретными
цветами и размерами: в компонентах только `var(--…)`, никаких hex и px
вне шкалы.

```css

 * Дизайн-токены. Единственное место с конкретными цветами и размерами —
 * редизайн меняет этот файл, а не компоненты.
 */
:root {
    --paper:      #f1f3ef;
    --paper-deep: #e4e8e1;
    /* Поднятая поверхность: светлее полотна страницы. Нужна там, где
       что-то лежит НА фоне, а не является фоном. */
    --paper-lift: #ffffff;
    --ink:        #1a1f1c;
    --ink-soft:   #5c6660;
    --rule:       #cdd4c9;

    --speak:      #6b2d5c;   /* фирменный акцент (слива) */
    --speak-bg:   #f3e9f0;
    --read:       #8a6a1f;   /* второй смысловой акцент (охра) */
    --read-bg:    #f5efdc;
    --warn:       #a33a2a;
    --warn-bg:    #f6e3df;
    --done:       #3f6b46;   /* доведено до конца */
    --done-bg:    #dcebdd;
    /* Третий смысловой цвет — динамика рейтинга. Той же светлоты и
       насыщенности, что слива и охра. */
    --trend:      #2f5f86;
    --trend-bg:   #e1eaf2;

    --mastery:    var(--done);

    --map-unit: 3px;

    /* Плеер сессии — сознательное отступление от «бумаги»: крупное скругление,
       капсулы и мягкая тень. Только для плеера и того, что внутри его рамки. */
```

### Как пользоваться акцентами в новом проекте

- `--speak` (слива) — **фирменный цвет семьи**, а не только «колода speak».
  Им окрашены: основная кнопка, фокус, ручки ползунков, заливка прогресса,
  галочки (`accent-color`), рамка поля ввода в фокусе, номер текущего шага,
  ссылки-кнопки. В новом проекте он остаётся главным акцентом.
- `--read` (охра) — второй акцент. Использовать только как **вторую сторону
  смыслового деления** (две колоды, два режима, две категории). Нет деления —
  нет охры.
- Если новому инструменту нужна своя пара категорий — переименуй токены
  по смыслу (`--cat-a`, `--cat-b` или по предметной области), **но значения
  оставь теми же**. Новые цвета не добавлять без смысловой причины; если
  очень нужен третий — подобрать той же светлоты и насыщенности, с парой
  `*-bg` и тёмной версией.
- `--trend` / `--trend-bg` (синий) — только динамика рейтинга во времени
  (график юнита). Добавлен в langa как третий цвет по правилу выше.
- `--mastery` — освоение юнита. Значение то же, что у `--done`, имя своё.
- `--learning-bg` / `--mastery-bg` — фон строки юнита, взятого в работу:
  учится (= `--read-bg`) и освоен (= `--done-bg`). Держится и при наведении.
- `--warn` — только ошибки и брак. `--done` / `--done-bg` — только «доведено
  до конца» (выгружено, завершено).
- Тёмная тема обязательна и работает через `prefers-color-scheme`, без
  переключателя.

### Шрифты

Inter Tight (интерфейс) и JetBrains Mono (данные) **едут вместе со сборкой**
из npm, а не с Google Fonts — инструмент обязан открываться без сети.
Нужны именно вариативные версии: в стилях есть веса 550 и 650.

```bash
npm i -D @fontsource-variable/inter-tight @fontsource-variable/jetbrains-mono
```

Подключение — первыми строками `base.css`, до токенов (сборщик сам положит
woff2 в сборку; браузер качает только нужные алфавиты по `unicode-range`,
кириллица в наборе есть):

```css
@import '@fontsource-variable/inter-tight';
@import '@fontsource-variable/jetbrains-mono';
@import './tokens.css';
```

Имена семейств в пакетах — с суффиксом `Variable`, поэтому в токенах стоит
`'Inter Tight Variable'`, а не `'Inter Tight'`.

## 4. Типографическая система

| роль | правило |
|---|---|
| заголовок экрана (h1) | `--t-xl`, `font-weight: 650`, `letter-spacing: -0.02em`, `margin: 0` |
| подзаголовок раздела (h2) | `--t-sm`, `600`, `uppercase`, `letter-spacing: 0.06em`, `--ink-soft`, `margin-top: --s-5` |
| подпись поля / колонки | `--t-xs`, `uppercase`, `letter-spacing: 0.05–0.06em`, `--ink-soft`, вес 500 |
| основной текст | `--t-md`, `line-height: 1.5` |
| подсказка, пояснение | `--t-xs`, `.muted`, `margin: 0` |
| главный объект в строке (слово, название) | вес `550–600` |
| числа, счётчики, пути | `.mono` |

Веса только 500 / 550 / 600 / 650 — без 700+. Капитель (uppercase +
разрядка) — для подписей и подзаголовков, никогда для основного текста.
Разделитель в строке метаданных — ` · ` (средняя точка с пробелами):
`в словаре 120 · в Noji 48`.

## 5. Компоненты

Только обычный CSS: без UI-библиотек, без CSS-фреймворков, без CSS-in-JS.
Классы BEM-подобные (`block__elem--mod`).

### Кнопка

```css
.btn {
    font: inherit; font-size: var(--t-sm);
    padding: var(--s-2) var(--s-4);
    border: var(--line); border-radius: var(--radius);
    background: transparent; color: var(--ink); cursor: pointer;
    transition: background 120ms, border-color 120ms;
}
.btn:hover:not(:disabled) { background: var(--paper-deep); }
.btn:disabled { opacity: 0.45; cursor: not-allowed; }
.btn--primary { background: var(--speak); border-color: var(--speak); color: var(--paper); }
/* Фон повторён намеренно: .btn:hover специфичнее .btn--primary. */
.btn--primary:hover:not(:disabled) { background: var(--speak); filter: brightness(1.15); }
.btn--quiet { border-color: transparent; color: var(--ink-soft); padding-inline: var(--s-2); }
```

Варианты: `default` (контур), `primary` (одна на экран — главное действие),
`quiet` (назад, отмена, второстепенное). Блок действий экрана —
`.row` с `padding-top: --s-4; border-top: var(--line)`; «назад» — quiet слева,
главное — primary справа.

### Пользователь и аватар

Справа в `.topbar`: имя (вес 550) + квадратная плитка 34×34 с радиусом
`--radius` (не круг). Цвет плитки выводится из имени: хэш → сетка из 12 тонов
по 30° и двух светлот:

```ts
const h = hash(name);  // h = (Math.imul(h, 31) + codePoint) | 0, затем Math.abs
`hsl(${(h % 12) * 30} 45% ${Math.floor(h / 12) % 2 ? 38 : 52}%)`
```

Поверх — зверёк DiceBear через `<img>` (не инлайн):
`https://api.dicebear.com/10.x/critters/svg?tags=animation&seed=<имя>`,
`width/height: 118%`, `object-fit: cover`, `object-position: 50% 12%`.
Не загрузился — первая буква имени белым на плитке. Те же формулы
→ у одного имени одинаковый зверёк и цвет **во всех инструментах семьи**.
Это главный сквозной знак экосистемы, его важно повторить точно.

Выпадающее меню: `--paper-lift`, `var(--line)`, `--radius`,
`box-shadow: 0 6px 20px rgb(0 0 0 / 12%)` (единственная тень в системе —
у того, что парит над страницей), `padding: --s-2`, `min-width: 220px`.
Закрывается кликом мимо и Escape.

### Поле ввода

`font: inherit; font-size: --t-sm; padding: --s-1 --s-2; background: --paper;
border: var(--line); border-radius: --radius`. В фокусе — `outline: none;

### Ползунки

Трек 2px `--rule`, заливка 2px `--speak`, ручка 14×14 круг: фон `--paper`,

Опорная риска на шкале — 1×12px `--ink-soft` с `opacity: 0.7`.

### Списки и таблицы

- Список — `list-style: none`, строки разделены `border-bottom: var(--line)`,
  отступ строки `--s-3` по вертикали. Никаких карточек-плашек для строк.
- Таблица: `border-collapse: collapse; table-layout: fixed; font-size: --t-sm`.
  Заголовки — капитель `--t-xs` вес 500 `--ink-soft`, линейка снизу.
  Числовые колонки — справа, `.mono`. Ширины колонок явные.
- Сортировка — сам заголовок-кнопка, стрелка всегда занимает место
  (`width: 0.7em`), чтобы заголовок не дёргался.
- Выключенная строка: `opacity: 0.35–0.4`, главное слово зачёркнуто,
  остаётся на месте. Галочки — `accent-color: var(--speak)`.
- Цитата/контекст: `border-left: 2px solid var(--rule); padding-left: --s-3;
  --t-sm; --ink-soft`.
- Брак в строке — полоса слева `2px solid var(--warn)` + текст замечания
  `--t-xs --warn` под содержимым. Принятый брак — та же полоса через
  `color-mix(in srgb, var(--warn) 35%, transparent)`.

### Показатели юнита в строке

У правого края строки, столбцом шириной `calc(var(--s-6) * 2)`: график — в
ряду названия, под ним в ряду описания — интервал и полоса освоения. Кнопка ▶
стоит сразу за последним словом названия.
- **График рейтинга** — высота `--s-5`, последние 4 недели, точка на день,
  шкала 0–100 одна на все строки. Линия 1.4px `--trend`, заливка под ней
  `--trend-bg`, базовая линия 1px `--rule`, точка «сегодня» r=2. Подъём — день
  практики, плавный спуск — тускнение между занятиями.
- **Стабильность** — интервал текущей ступени в днях, `.mono --t-xs` вес 550,
  единица «дн» `--ink-soft`. Всегда в днях, чтобы ширина не скакала.
- **Освоение** — полоса 2px `--mastery` на треке `--rule`, справа от числа до
  края столбца.
- Без практики — пусто: ни графика, ни числа, ни полосы.
- Юнит не в работе, но с рейтингом (решал из каталога или когда-то начинал) — показатели
  видны только в раскрытой строке и бледные, `opacity: 0.4`.
- Значения — подсказкой при наведении, как у выпадающего меню (`--paper-lift`,
  тень), `.mono --t-xs`, по строке на показатель.

### Карта юнитов

Между плеером и списком юнитов области — квадраты 3×3 (`--map-unit`), по квадрату
на юнит в порядке `position`, разделы отделены зазором не меньше `--s-2`, внутри
раздела — 1px; размер везде один. Не помещается в ширину колонки — перенос
целыми разделами на следующую строку (между строками `--s-2`). Строка, занявшая
не меньше ¾ ширины, растянута на всю (растут только разрывы между разделами),
кроме последней из нескольких; остальные — разрывы фиксированные, прижаты влево.
Грамматика (163 юнита) встаёт в одну растянутую строку, лексика (101) — влево. Цвет — тот же смысл, что фон
строки, но насыщенный: не начат — `--rule`, в работе — `--read`, освоен —
`--mastery`. Подсказка при наведении — как у показателей юнита (номер и
название, ниже раздел и статус); у правой половины прижата вправо. Клик —
переход к строке юнита с подсветкой. С клавиатуры квадраты не достаются
(те же строки ниже), для экранного чтеца карта — одна фраза
«Освоено N из M, в работе K».

Та же карта — под строкой каждой области в `/catalog`: клик ведёт на страницу
области к строке юнита, строка подсвечивается при открытии.

### Статья юнита

Текст для человека в раскрытой строке юнита — перед guide, тем же тихим видом (`--t-sm`, подзаголовки капителью), но выделение `*…*` — вес 550, а не цвет брака: в статье это акцент, не ошибка; `**…**` — вес 600. Ссылки — `--speak`. Встроенные элементы — блоками на всю ширину колонки статьи:
- **Видео** — 16:9 по ширине, `--radius`, фон `--paper-deep`, пока грузится.
- **Звук** — системный `<audio controls>`, справа в строку подпись `--t-xs --ink-soft`.
- **YouGlish** — абзац из одной или нескольких ссылок YouGlish (голые URL или `[подпись](URL)` через пробелы, запятые или « · ») — один виджет со списком слов. До нажатия обычная контурная `.btn`: значок play `--speak`, подписи вес 550 через « · » («made · mad · pain · pan»), «— в живой речи (YouGlish)». Значок — инлайн SVG, а не символ ▶: тот на части систем рисуется эмодзи. Пока грузится скрипт — спиннер на месте значка, кнопка не бледнеет. Затем на месте кнопки наш виджет вокруг их видео: не шире 480px, `--paper-lift`, `var(--line)`, `--radius` (лежит на фоне строки, как «Как лучше»). Сверху наше, снизу их:
  - строка управления — слева одно слово вес 550 или, у списка, переключатель слов `.choice` (выбрано первое; подпись — текст ссылки, у голого URL — слово). Если акценты в списке разные — у подписи мелко `UK` / `US` (0.6875rem, прозрачность 0.7), одинаковые не показываются. Счётчика и прочих надписей нет. Справа одной группой — не влезла рядом со словами, переносится целиком под них к правому краю — иконочные кнопки ‹ (предыдущий), › (следующий), ↻ (ещё раз), переключатель скорости `.choice` «0.75 · 1» (выбранная скорость держится при смене слова и примера), × — свернуть обратно в плейсхолдер (фокус возвращается на него);
  - субтитр — шрифт статьи `--t-sm`, место на две строки (длиннее — многоточие), чтобы виджет не прыгал; текст прижат вниз — короткая фраза стоит у видео (зазор `--s-2`), пустое место над ней; зазора между строкой управления и местом субтитра нет; искомое слово — маркер: фон `--speak-bg`, цвет `--ink`, вес 550 (не цвет `--speak`: им у нас ссылки). Пока ищет — `.muted` «Ищу примеры…», не нашлось — «Примеров не нашлось.», между фразами — пусто;
  - iframe YouGlish без их интерфейса, обрезанный по плееру (`overflow: hidden`): их рекламный блок и «powered by» под видео уходят за край. Плеер в их iframe не 16:9: при ширине 454 он занимает полосу 1–215px, поэтому высота окна — постоянная 216px (`YOUGLISH_VIDEO_HEIGHT`), а не от ширины. Изменится их вёрстка — из-под края покажется зазор или реклама, обрезка видна сразу; отдельной защиты нет. Цвета iframe — из токенов на момент открытия (`--paper-lift`, `--paper-deep`, `--ink-soft`, `--speak`, `--speak-bg`), шрифт внутри — их.

### Разбор открытого ответа

Группировка по действию, а не по устройству оценки, сверху вниз:
- **Итог** — между двумя линейками: вердикт `--t-lg` вес 650 (верно — `--done`, в том
  числе «Верно, есть другие ошибки» — целевой юнит засчитан; ошибки — `--warn`, «без нужной конструкции» — `--ink`), под ним пояснение
  `.muted --t-sm`; справа балл целевого юнита `.mono --t-xl` и подпись
  `--t-xs` «целевой юнит · статус».
- **Исправь** — все правки одним нумерованным списком (целевой юнит первым,
  побочные от худшего, затем вне юнитов). Строка — брак в строке: полоса
  `2px --warn`, правка `--t-md` «~~было~~ → стало» (`--warn` / `--done` вес 550,
  без подчёркивания), под ней комментарий и юнит `--t-xs`.
- **Как лучше** — на `--paper-lift` (лежит на фоне строки, а он меняется):
  подпись капителью слева, текст справа — твой (приглушённо), исправленный,
  носитель, эталон.
- Юниты без ошибок — одной строкой `.muted --t-xs`; удачные — «Отлично» `--done`.
- Повторная попытка — та же подложка `--paper-lift`: «Показать разбор» quiet
  слева, «Проверить» primary справа.

### Плеер сессии (исключение)

Единственный виджет вне «бумаги»: рамка на `--paper-lift` со скруглением
`--radius-lg`, тенью `--shadow-lift`, кнопки и переключатель длительности —
капсулы `--radius-pill`. До старта — полоска: ▶ и справа длительность; на
старте рамка раскрывается по высоте (360ms), по «Завершить» сворачивается
обратно (300ms) — исключение из раздела «Движение». Старт, каждое следующее
задание и показ результата прижимают к верху окна экран с плеером — от заголовка
области (h1), а не от рамки — быстрой прокруткой (220ms); фокус на «Дальше» и
«Завершить» ставится без прокрутки, чтобы окно не уезжало к низу рамки. В сессии сверху
таймер (по истечении — фон `--warn`, счёт дальше без минуса), след ответов и
«Завершить», снизу «Пропустить» / итог фоном `--done-bg` или `--warn-bg` и
«Дальше». Таймер — он же кнопка паузы: при наведении фон `--speak-bg`, цвет
`--speak` и значок паузы на месте мигающей точки, на паузе — ▶ и цифры
`--ink-soft`. До первого задания и после конца времени не нажимается. Уход со
вкладки или из окна ставит паузу сам (константа `AUTO_PAUSE`), снимается она
только вручную. На паузе задание и нижнюю полосу закрывает слой
`--paper-lift` с прозрачностью 95% и `backdrop-filter: blur(5px)` — без текста
и кнопок; блюр — только здесь. В левом нижнем углу задания — копирование
плеера картинкой: иконка 12×12 в кнопке 16×16 (меньше обычной, чтобы
уместиться в отступе), невидима, пока мышь не рядом (зона с запасом `--s-2`),
у значка — 0.5, на самом значке — 1; итог — `ok` или `cancel` на 1 с; та же кнопка
в том же углу — на экране итога сессии; с
клавиатуры не достаётся. Задания внутри — те же компоненты, что в строке юнита. Конец
сессии — по времени или по «Завершить» сверху — экран итога: таблица юнитов
по правилам «Списки и таблицы» — только тех, у кого сдвинулась хоть одна из трёх
шкал (в видимом округлении), по `position`; ничего не сдвинулось — вместо таблицы
строка `.muted` «Рейтинг ни одного юнита не изменился.»; «было → стало» `.mono`, рост `--done`,
падение `--warn`, под юнитом мелко его задания; внизу «Завершить» сворачивает
плеер. Эти токены вне плеера не использовать.

Показывает учебную карточку так, как её увидят при повторении. Двойная рамка
в цвет категории; это исключение из правила «радиус 3px».

```css
.side--speak { --deck: var(--speak); --deck-bg: var(--speak-bg); }
```

Экран — `.stack` (вертикаль с `gap: --s-4`). Слева состояние, справа

Список-вход (рабочие области в `/catalog`): строка — как строка списка (линейки,

вес 550, справа счётчики `.mono --t-xs` через ` · `; под ней карта юнитов области
(«Карта юнитов»), вне ссылки.

## 7. Движение

Только `transition` 120ms на фон/цвет/рамку и 200ms на ширину прогресса.
Никаких появлений, сдвигов, пружин. `prefers-reduced-motion` гасит всё.

Исключение — раскрытие строки списка вниз по клику: 360ms по высоте через
`grid-template-rows: 0fr → 1fr` (обёртка с `overflow: hidden; min-height: 0`),
кривая `cubic-bezier(0.2, 0, 0, 1)`, без прозрачности и сдвигов. Переключает
шапка строки — кнопка с `aria-expanded`; раскрытая строка остаётся на фоне
`--paper-deep`.

Второе исключение — выбор типа задания у ▶ в строке юнита: при наведении слово
типа выезжает вправо из-под ▶ на общей с ней плашке `--paper` без рамки, 200ms,
та же кривая, через `clip-path`; поверх строки, без сдвига текста.

Ожидание ответа сервера на месте кнопки, которая его вызвала: спиннер
14×14 (кольцо 1.5px `--rule`, верхняя четверть `--speak`), вращение 0.8s.
При `prefers-reduced-motion` остаётся неподвижное кольцо.

Переход по якорю к строке списка: прокрутка `scroll-behavior: smooth`, строка
3s угасает от `--speak-bg` к своему обычному фону (половину времени держит,
затем `ease-out`). Подсветка временная — постоянный фон после перехода не
остаётся.

## 8. Текст интерфейса

- Язык интерфейса — русский, `<html lang="ru">`.
- На «ты», коротко, глаголом: «Перетащи файл сюда», «Выбрать файл»,
  «Разбираю книгу…», «Книг пока нет. Загрузи первую — дальше словарь будет
  копиться сам».
- Процесс — глагол в настоящем с многоточием (`…`, один символ).
- Тире — длинное `—` с пробелами; диапазоны — `1 — 5` в `.mono`.
- Без восклицательных знаков, без «Упс», без эмодзи.
- `<title>` — имя инструмента строчными, как `ankibook`.

## 9. Чего не делать

- Не подключать Tailwind, MUI, shadcn, иконки-библиотеки, Google Fonts
  и любые другие шрифты, кроме двух из раздела «Шрифты».
- Не вводить новые цвета, тени, радиусы и размеры вне токенов.
- Не красить ради красоты: цвет = смысл.
- Не использовать вес 700+, курсив (кроме пометки пустого значения),
  подчёркивание (кроме `.linklike`).
- Не прятать отключённое — бледнить на месте.
- Не делать плашки-карточки для строк списков и разделов: разделитель —
  линейка 1px.

## 10. Стиль кода стилей

Комментарии в CSS — по-русски и объясняют **почему** (например: «Фон повторён
намеренно: `.btn:hover` специфичнее…»), а не что. Общие примитивы — в
`base.css`/`App.css`, а не в CSS первого попавшегося экрана: иначе вид блока
зависит от того, смонтирован ли чужой компонент.
