# CLAUDE.md

Этот инструмент — часть семьи с AnkiBook (лексика из английских книг →
карточки для Noji/Anki). Он должен выглядеть и ощущаться как продукт той же
экосистемы. Личный инструмент, один пользователь.

## Визуальный стиль

Строго по DESIGN.md — токены, шрифты, компоненты, тон текстов, запреты:

@specs/design.md

Любой новый экран или компонент сначала сверять с DESIGN.md. Если нужного
приёма там нет — собрать его из существующих токенов и примитивов, а не
изобретать новый цвет, тень, радиус или размер.
